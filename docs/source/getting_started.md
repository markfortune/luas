# Getting started

`luas` is well-documented and contains [tutorials](tutorials_index) which should help you get started. Our paper [Fortune et al. (2026)](https://github.com/markfortune/luas_dev) should be a useful reference to understand the optimisations and motivation behind `luas`, but you can see [Why use luas?](why_use_luas) for a summary of the computational benefits that `luas` can offer, and [luas for exoplanets](luas_for_exo) could be helpful if applying the package to exoplanet astronomy. Information about installation and dependencies is covered in [Installation](installation).

As `luas` is implemented in [`jax`](https://github.com/google/jax), we would recommend getting some familiarity with `jax` if you've never used it before. [Working with JAX](things_to_know) should be a useful starting point.
